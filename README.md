# ⚔️ hamnajalil.com — an RPG-themed portfolio

**Live:** https://hamnajalil.com

The interactive portfolio of Hamna Jalil, a Technical PM, Game Producer and AI & Technology Lead. It works like an RPG world rather than a static CV: you explore it to find the career quests, the boss fights, and the PM tools.

## ✨ What's inside
- **Explorable world:** a dark, game-inspired single-page site with procedural canvas animations
- **Game feel:** custom cursor, Web Audio sound effects, depth colours and ambient motion
- **Career as quests:** AAA (Skyborne: Phoenix Flight), Web3, live service and SaaS work told as an adventure
- **PM tools:** interactive production and planning tools that blend game design with PM craft
- **Resume:** [HAMNA_JALIL.pdf](HAMNA_JALIL.pdf)

## 🛠️ Built with
Vanilla HTML, CSS and JavaScript in a single `index.html`, with no frameworks and no build step. It's hosted on GitHub Pages with a custom domain, and built with AI pair programming (Claude Code).

## 🎮 Why an RPG?
I've spent 6+ years shipping games. A portfolio should *feel* like the work, not just describe it.
